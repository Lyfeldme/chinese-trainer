Как добавить свои слова

Приложение поддерживает три способа пополнить словарик своими словами.

1
Вручную
Нажмите «Добавить слово» в разделе «Мои слова» — откроется форма. Заполните иероглифы, пиньинь, перевод и (по желанию) пример употребления.
2
Через готовый шаблон
Нажмите «Шаблон» — скачается файл hanzipath-template.json с примерами и подсказками. Отредактируйте его в любом редакторе и загрузите через «Импорт».
3
Свой JSON-файл
Создайте массив объектов по схеме ниже — и загрузите его через кнопку «Импорт». Поддерживаются два формата: массив слов или { "section": "…", "words": […] } — второй создаёт отдельный раздел.

Схема JSON

[
  {
    "word": "包子",
    "pinyin": "bāo zi",
    "translation": "баоцзы (паровые пирожки)",
    "examples": [
      {
        "zh": "我早上吃包子。",
        "pinyin": "wǒ zǎo shang chī bāo zi",
        "ru": "утром я ем баоцзы"
      }
    ]
  }
]

Поля слова

word обязательно китайские иероглифы
translation обязательно перевод на русский
pinyin опционально пиньинь с тонами: bāo zi
examples опционально массив предложений — включает режимы «Пропуски» и «Диктант»

Поля примера предложения

zh обязательно предложение на китайском
pinyin опционально пиньинь предложения
ru опционально перевод на русский

Советы

  • Сохраняйте файл в кодировке UTF-8 — иначе иероглифы превратятся в «кракозябры».
  • Импорт можно запускать многократно. Слова с одинаковыми иероглифами обновляются, новые — добавляются.
  • Формат { "section": "…", "words": […] } создаёт отдельный раздел — его можно удалить в статистике.
  • Записи с полями _comment, _readme, _schema игнорируются — их можно оставлять для документации.
