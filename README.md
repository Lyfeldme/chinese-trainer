# HanziPath

Тренажер китайских иероглифов, работает прямо в браузере.

## Возможности

- 🔤 Слово, пиньинь и перевод
- ▶ Анимация порядка черт
- ✏️ Режим «Писать» — строгая проверка каждой черты (мышкой или пальцем)
- 🖌 Режим «Обводить» — свободное рисование поверх контура
- 🔊 Озвучка через Web Speech API (`zh-CN`)
- 💾 Прогресс сохраняется в localStorage
- ⌨️ Горячие клавиши: `→` след. слово, `A` анимация, `Q` писать, `T` обводить, `S` озвучка

## Запуск

Откройте `index.html` двойным кликом — **сервер не нужен**.
Проект использует обычные `<script>` и глобальные объекты, без ES-модулей.

## Структура

```
hanzi-trainer/
├── index.html
├── README.md
└── assets/
    ├── css/    reset, variables, main, components
    └── js/
        config.js    — настройки
        data.js      — массив слов
        storage.js   — прогресс в localStorage
        audio.js     — озвучка
        writer.js    — обёртка Hanzi Writer
        quiz.js      — режим «Писать»
        trace.js     — режим «Обводить»
        ui.js        — статус, список слов, прогресс
        main.js      — точка входа
```

## Как добавить свои слова

Откройте `assets/js/data.js` и добавьте в массив `HP_WORDS`:

```js
{ word: '电影', pinyin: 'diàn yǐng', translation: 'кино' },
```

## Как сбросить прогресс

В консоли браузера: `HanziPath.resetProgress()`
