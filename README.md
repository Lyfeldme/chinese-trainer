# Тренажёр для изучения китайского языка: слова, иероглифы, порядок черт, произношение и практика.

## Возможности

- 📚 Словари HSK 1–6 + свои слова и разделы
- ✍️ Тренажёр письма с проверкой порядка черт
- 🧠 Режим «По памяти» и «Обводить»
- 🔊 Озвучка слов и примеров (Web Speech API)
- 📖 Проверка предложений, диктант, пропуски
- 🀄 Конструктор прописей с печатью (田字格 / 米字格 / 九宫格)
- 🔁 Интервальное повторение (SRS) с 9 уровнями
- 📊 Статистика: серия дней, слабые слова, экспорт/импорт прогресса
